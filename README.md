## The tip

> Tip: if your agent has been "almost done" for 40 minutes, it is not almost done. Go for a walk. It will delete the wrong file faster without you watching.

154 characters, one line — a real loading-screen tip for a stressed developer
*and* their AI coding agent. The agent that has been "almost done" for 40
minutes is not almost done, and it will delete the wrong file faster without
you watching.

## How it works

`main.py` writes the exact tip (154 characters, no trailing newline) to
`/output/entry.txt`, then reads it back and asserts it matches the constant.

```sh
python3 main.py
```
